# 图元、符号与正向实体

## 规范依据

格式依据为 [ODB++ 8.1 Update 4](../reference/format-sources.md)：p.34–40 说明变换、符号拖拽、极性与轮廓，p.166–180 说明图元记录，p.187–205 给出标准符号。

| 记录 | 几何含义 | Parser 处理 |
| --- | --- | --- |
| P | 指定位置及方向的符号 | 展开尺寸、resize、旋转、镜像与平移 |
| L | 符号中心沿直线拖拽 | 以符号实体扫掠路径 |
| A | 符号中心沿圆弧拖拽 | 弦高离散与符号扫掠，整圆保留闭合末段 |
| S | 面实体 | 读取 OB / OS / OC / OE / SE 边界并规整 |
| T / B | 文本 / 条码 | 按明确的范围排除项给出 unsupported 诊断 |

OB 的 I / H 声明岛与孔；输出边界岛顺时针、孔逆时针，同时携带显式 island 标记。
孔内岛是实体，材料实体同向重叠表示并集；负图元的作用由输入顺序决定。

## 标准与自定义符号

基础符号包括圆 `r`、方 `s`、矩形 `rect` 和长圆 `oval`，参数采用 µm / mil 专用单位。
例如 MM `rect1000x500` 对应 1×0.5 mm，`oval1000x500` 沿长轴连接两个半圆帽。
圆角、倒角、环形和其他符号族由完整命名文法判定，支持范围由实现与测试明确列出。

名称不符合标准文法时读取 `symbols/<name>/features`，其中仍可引用符号或包含 S / OC 圆弧。
递归加载使用引用环检查与深度保护，未被引用的定义不参与展开。
真实样本中的 `special_*` 名称说明首字母不能决定符号类型。

## 扫掠、极性与精度

规范的拖拽是中心平移。方符号沿斜线保持轴向；边长 1 mm 的方符号沿向量 (5,5) 拖拽，实体面积为 11 mm²。
圆符号使用半径偏移保证带宽，圆帽与圆弧按弦高容差近似；自定义符号的扫掠近似需有显式诊断。

图元按有效极性连续运行段处理，段内并集、段间保序。负性层从有效基底出发，介质从有效 profile 出发。
规整后输出只有实体岛孔语义。最终坐标量化后重新检查自接触、退化和岛孔，JSON / SVG / HTML 共享最终规整坐标。
Parser 的内核量化、输出坐标分辨率与等效器材料光栅分别控制不同误差。

## 物理边界与验证

介质 JSON 保留未扣钻孔的基底，预览在绘图副本中扣孔；铜图案独立于 DRILL。
profile 的真实挖空属于几何域，采样钻孔则属于材料投影。
典型断言包括闭合环带有孔、同向叠加不抵消、负性层基底合成和量化后的坐标 / 面积自洽。
实现假设及未由生产样本证实的参数读法见 [解析决策](../decisions/pcbkit/parser-semantics.md)。

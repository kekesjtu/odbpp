# 解析语义与几何展开

## 单位、记录与实体名

坐标和一般尺寸按文件作用域的 MM / INCH 解释；标准符号参数、resize、钻孔尺寸按规范专用的 µm / mil 语义解释。
输出几何统一为 mm。`misc/info` 缺省单位按 INCH 处理并警告。
属性名和值表在解析记录时实时可见；布尔裸索引表示 true。

matrix 决定层目录，实体名匹配忽略大小写，保留原始身份用于输出。
缺 ROW 时按文件顺序编号，BOARD / MISC 均可读取，由消费者判断用途。
FORM 按显式声明、挠性子类型、规范 RIGID 默认的优先级解释，并保留 `form_source`。
介质缺 FORM、声明与子类型冲突、未知声明分别给出诊断。

## 极性与扫掠

图元按有效极性切成连续运行段，段内并集、段间按文件顺序累积。
介质和负性层按各自有效基底播种；层极性与记录极性分别处理。
输出是正向实体边界集合，岛顺时针、孔逆时针，并显式记录 `island`。
SVG 使用规整实体的 nonzero 填充；同向材料重叠表示并集。

L / A 表示符号中心沿路径平移扫掠。圆符号以半径偏移构造带宽，方符号保持轴向做 Minkowski 扫掠，自定义符号递归展开。
整圆使用闭合中心线，覆盖闭合末段及内部孔洞。零宽图元的有限宽度显示替代使用显式参数和警告。
标准符号必须通过完整命名文法，`special_*` 等名称按自定义符号查找；定义按引用惰性加载，并检查递归环。

## 坐标与交付

Clipper 坐标量化为 1e-6 mm，最终输出采用用户指定的小数分辨率。
量化仅去相邻重复点及冗余闭合点，自接触路径交由布尔规整，输出端重新检查环、岛孔和退化。
step / layer profile 与材料图案使用一致的离散与输出精度。JSON、SVG 和 HTML 由同一最终规整视图交付。
几何算法负责拓扑，Pydantic 校验字段、引用、有限性、跨度和必要来源。

## 需要真实样本继续复核的假设

| 主题 | 实现读法与证据边界 |
| --- | --- |
| apt_def resize | 按 µm / mil 的总宽度增量处理，边界偏移半量，使用圆角；触发 `geometry.resize_unverified` |
| rect 角掩码 | 按规范正文从右上角逆时针编号 1–4，非法编号拒绝；正文与示例有冲突 |
| oct 缺省角切 | 使用 w×h 框内相切的八边形；缺省形状依赖实现约定 |
| hex_l / hex_s | 按完整 w×h 包围盒构造六边形 |
| oval_h | 取 y≥0 的半长圆并以直径闭合 |
| 负片层的负记录 | 采用层极性与记录极性 XOR，合成夹具固化该读法 |

这些假设的实证状态与输入案例关联，合成覆盖不替代生产样本验证。
范围中明确排除的 T / B 记录仍以 `features.unsupported_record` 报告。
规范页码与输入观察见 [格式调研](../../research/format-and-units.md)。

# 离线查看器交互

## 决策与使用范围

Parser 生成自包含 HTML，SVG、样式和脚本均内联，支持离线打开。
查看器使用解析后的矢量和统计，服务于层图案、轮廓、叠层和几何检查。
工程数值交接使用中间 JSON，等效物性以 MaterialMap 为准。

可选逐层 PNG 由 Python 从同一绘图几何生成，包括空图层。各层共享毫米比例和视窗，Y 轴向上；最长边为 1600 像素，白底、材料着色，孔洞和嵌套实体明确区分。介质采用与 SVG 相同的钻孔绘图副本。PNG 随解析器事务发布并登记在产物清单中。

## 图层、属性与坐标

复选框控制可见性，行选择查看属性，双击或 Enter 隔离图层。搜索仅过滤列表。
原始板框、选中层轮廓与铜图案分别显示；层叠矩阵按 matrix 行号展示类型、上下文、绝对 Z、厚度可信状态与来源。
板框导航、定位选中层、缩放、平移和两点测距使用毫米坐标。测距表示任意两点距离。
输入图元统计保留类型、极性、符号和有效单位作用域；BOARD 层输出实体使用 Parser 规整结果；MISC 层按有序绘图指令预览，保留原始极性、符号放置及笔画宽度，不提供实体面积。

## 钻孔跨度矩阵

矩阵箭头端帽对齐 START_NAME 对应行中心，箭头对齐 END_NAME 对应行中心，名称匹配忽略大小写并保留声明方向。
重叠跨度分配不同列，互不重叠的跨度可共列。选择钻孔、对应列表行或箭头时，箭头与两端名称共同高亮。
选择保持现有图层可见性；键盘可选择矩阵行与箭头。
端点无法唯一解析时显示跨度未解析；箭头位置按实际行高更新，支持滚动、换行及窗口变化。

# 轮廓近似 region 与局部网格

## 有效 profile 与复用

各物理层的有效计算域为层实体范围与整板实体范围的交集。几何相等以此交集的实体点集为准，不依赖 profile ID、顶点起点、绕序、共线点或输入轮廓超出整板的部分。同几何仅规划一次，所有引用层复用完全一致的二维 region 与局部网格；每层仍独立计算材料物性。

不同几何独立划分，不要求跨层 region 上下对齐。每个 profile 内部的轴对齐矩形互不重叠；不同 profile 的二维投影允许重叠。二维矩形与引用层的完整 Z 区间定义三维 region。

## FAST 轮廓近似

使用 [Mohr、Zachmann，FAST，第 3.1 节](https://cgvr.cs.uni-bremen.de/papers/bmvc2010/mohr_bmvc2010.pdf) 的原始三阶段流程：按公式 (5) 递归寻找宽高各减半的最高收益窗口，直到窗口完全位于剩余前景；按公式 (4) 移动矩形四边，提高收益；按面积门槛 r 接受矩形或暂时禁用该区域，搜索耗尽后恢复区域并降低门槛。接受的矩形不得重叠。

轮廓在均匀二值光栅上搜索，最长边 1024 像素，短边按物理宽高比取整，最少一像素。tau 固定为论文实验的 0.95。每格按一个像素计分，不注入轮廓顶点、孔洞见证点或连接保护。选出的矩形直接输出，不作额外合并。搜索独立于材料采样 Px/Py。

整数离散规则为：半尺寸向下取整、最少一像素；同收益候选按 Y 后 X 的顺序选择；每次移动一条边一个像素，选择严格改善收益的移动，直到没有改善；面积不少于 r 时接受，保证最小像素块可被选择。论文未指定这些离散边界细节，运行诊断记录相应约定。

## 精度与结果诊断

`--max-area-error-ratio` 默认 `0.05`，须有限且位于 `[0,1)`。停止条件为原始前景与矩形集合的光栅对称差像素数不超过原始前景像素数乘以预算。前景擦除只影响后续搜索，新增背景始终计入误差。资源耗尽或无法达到目标时报告失败，不更换 tau 或重试搜索分辨率。

最终矩形恢复到毫米坐标后，独立计算真实矢量轮廓的漏失、新增、对称差比例、净面积偏差和 IoU。矢量误差可能与光栅误差不同，须分别交付。实体、孔洞、连接和多尺度核心保留情况只作诊断，不参与选块、补块或停止判断；原版 FAST 不保证拓扑保持。

近似矩形超出原始有效域的部分统一采用本层基底材料。物性作用于完整模型单元，不按原域覆盖率缩减体积、质量或热容。几何误差不等于热仿真误差。

## 局部均匀网格

各三维 region 独立划分均匀笛卡尔网格。X/Y 分格数按完整边长 L 与各轴上限 max 取 `max(1, ceil(L/max))`。短边完整保留为一个单元，长边继续等分。各 region 保留自身边界，相邻网格允许不共形。Z 方向完整对应所属层，分格数为 1。

常规档位为 `coarse / standard / fine`，默认 `standard`。尺寸估算结合整板范围和矢量铜图案的特征尺度。单个图案以 `2A/P` 估计宽度，使用不小于 0.01 mm 的候选的第 10 百分位作为代表值。

| 档位 | 整板范围尺度分母 | 代表特征乘数 |
| --- | ---: | ---: |
| coarse | 32 | 24 |
| standard | 64 | 12 |
| fine | 128 | 6 |

整板尺度候选为 `sqrt(X跨度 × Y跨度) / 分母`。目标上限取整板候选和可用特征候选的较小值，再以最长边 / 512 作为估算下界。依据和最终尺寸写入 `grid.mesh_configuration`。

专家模式用 `--max-cell-mm` 提供一个共用上限或 X/Y 两个上限，均须有限且正，与档位互斥。库内专家默认上限为 5 mm。每个 region 单轴最多一百万分格，整板最多五百万 XY 建模单元，超限报错。

网格完成后才检查 [材料采样容量](material-sampling.md)。只修改 `Px/Py` 时，region 和物性网格坐标保持不变。[MaterialMap 接口](../../interfaces/materialmap.md) 定义网格范围、分格数和物性顺序。

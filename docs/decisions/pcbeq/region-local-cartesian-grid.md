# Region 局部笛卡尔网格与最大尺寸

## 决策

每个实际 region 独立采用均匀笛卡尔网格。X/Y 分别以本 region 的完整长度 L 按上限 max 等分，分格数为 `max(1, ceil(L/max))`。
相邻 region 的网格线不传播、不要求共形，允许 T 形接缝；每个单元完整位于一个 region 和一个物理层内。
各层共享物理 region 几何与层存在性判定；每个三维 region 的 Z 对应该层完整区间，`nz=1`。
MaterialMap 用 region 的 XYZ 最小/最大边界及 `grid_counts{x,y,z}` 唯一恢复网格，单元物性按 X 最快、Y 次之、Z 最慢排列。采用参考 CSV 的“范围 + 分格数”表达思路，自定义 JSON 不承诺 Flotherm 导入兼容。

## 常规档位与专家尺寸

常规 `coarse / standard / fine` 默认 standard，物理尺寸依据原始 step 范围与正向铜图案特征估算。
每个铜多边形以 `2A/P` 估计宽度，记录最小值，取不小于 0.01 mm 的候选中第 10 百分位作为代表特征值。
该值是细长图案近似宽度，孔洞、网络及离散边缘会影响估计；过滤仅影响尺寸建议。

| 档位 | 整板面积平方根分母 | 代表特征乘数 |
| --- | ---: | ---: |
| coarse | 32 | 24 |
| standard | 64 | 12 |
| fine | 128 | 6 |

整板尺度候选为 `sqrt(X跨度 × Y跨度) / 分母`。目标上限取它与特征尺度候选的较小值，再以最长边 / 512 限制建议尺寸的计算成本。
这是档位最大尺寸建议的估算下界，真实短 region 仍完整保留。
档位依据、过滤数量和最终上限写入 `grid.mesh_configuration`。

专家 `--max-cell-mm` 接受一个值或 X/Y 两值，均须有限且正；专家配置默认上限为 5 mm。
输入提供最大边长，各 region 的 nx / ny、最短边和单元数由其物理范围独立派生。

## 几何独立性与资源

规划仅消费物理轮廓、域、拓扑、误差预算和物理尺寸；Px/Py 只参与后续采样容量检查。
所有 region 边界保留；其他 region 的边界不细分本 region。受约束的 region 简化减少物理边界坐标种类和几何块数，不将这些边界坐标作为全板物性轴线。
每个 region 单轴分格超过一百万、整板 XY 单元超过五百万时报告几何资源错误。
采样容量不足时保持几何并报错，默认光栅可在几何确定后加密。

## 依据与实现对照

局部均匀划分使下游只需 region 范围与三轴分格数即可恢复全部单元。短边不引入其他 region 的强制细分；长边仍遵守最大尺寸。
几何预算见 [内接 region](inscribed-regions.md)，采样阈值见 [材料采样](material-sampling.md)。

# 内接 region 与面积误差控制

## 精度参数

region 划分只提供一个精度参数：`--max-area-loss-ratio`，默认 `0.05`，表示允许损失原始有效计算域面积的 5%，取值必须有限且在 `[0,1)`。
预算按每个有效层域及待等效物理域并集分别检查，不用一个域的剩余额度补偿另一个域。
面积预算不限制局部轮廓退缩距离；小面积边界特征可以在预算内省略，但不得破坏下述实体与拓扑约束。

## 几何约束

- 使用轴对齐、互不重叠的竖条阶梯内接矩形。
- 每条带直接取整个 X 区间共同存在的真实 Y 区间；Y 坐标不取整，不引入 Y 格点。
- 每个 region 必须完整位于 step profile 与所属物理层域内，不能向板外或孔洞扩张。
- 保留独立实体、孔洞和正宽连接；不切断柔性连接，不以光栅中的连通性代替矢量检查。
- 面积预算不能豁免拓扑保护；资源限制内无法同时满足约束时必须报错。

拓扑保护采用实体与孔洞一一对应、孔洞包含性、正宽连接及原始几何腐蚀核检查。腐蚀半径为 0.03125、0.1、0.25、0.5、1 mm，属于固定的内部特征保护策略，不是精度参数。
包含性谓词只允许浮点舍入量级的容差，不移动实际几何。

## 自适应划分

正交轮廓直接使用真实 X 顶点区间。其他轮廓使用内部 0.25 mm 初始条带；诊断或测试可通过库内选项设置种子尺度，产品命令不公开该选项。
每条带计算真实实体面积与共同 Y 区间模型面积的差值。
面积损失超预算时，优先二分损失最大的条带；面积达标但拓扑不满足时，继续在有损失的位置局部细化，优先处理没有保留截面的实体区间。

初始条带最多 10,000 条，最多逐次二分 10,000 次，单条带最多二分 20 层，最小 X 条带宽度为 `1e-5 mm`。
小于 `1e-8 mm` 的数值截面不作为正宽区间，任何因此造成的实体、孔洞或连接丢失仍必须被拓扑检查拒绝。
终止诊断须包含 X 区间、长度、损失与预算、细化深度和次数。

## 相邻合并与共享层域

相邻条带可以收缩到共同真实区间，合并候选只能提高下限或降低上限，不得外扩。
相同成员身份且边界完全相接的矩形可以无损合并；不同层成员身份必须保留必要接缝。
每个有损候选都检查面积、内接与拓扑，不计算轮廓距离、距离缓冲区或退缩上界。

候选优先简化相距不足 0.1 mm 的边界坐标，再减少边界坐标种类和 region 数。0.1 mm 是内部排序偏好，不是最小网格尺寸或 Y 量化尺度。
独立域合并最多 12 轮；共享分区最多接受 256 次候选，不承诺全局最少矩形数。

step 与逐层模型相交、形成共享分区后，对每个域重新检查用户面积预算与拓扑。
共享层域复检失败时，可将独立域规划面积预算依次收紧为用户值的 1、1/2、1/4、1/8、1/16；最终共享分区始终遵守原用户预算，不放宽约束。实际内部预算和重规划结果写入诊断。
仅作为 step 参考、没有任何物理层存在的分区不输出实体；根模型按待等效物理域并集统计面积损失。

## 网格、采样与输出

region 规划只读取物理坐标、域和几何参数，不读取光栅、铜像素比例或材料掩膜。
各 region 再独立按最大单元边长划分局部均匀笛卡尔网格；光栅在几何确定后检查采样容量。
只修改 Px/Py 时，region 与物性网格坐标必须不变。

诊断记录原始面积、建模面积、损失与比例、用户面积预算、内部规划预算、内接性、拓扑、局部细化和共享域重规划。
内接面积的数值容差为 `1e-8 mm²`，不能作为额外物理损失预算。
Rust 执行完整 JSON 到 MaterialMap 流程；Python 仅作其命令启动和 MaterialMap 可视化。

局部网格规则见 [region 局部笛卡尔网格](region-local-cartesian-grid.md)。

# 独立材料采样与钻孔覆盖

## 决策与范围

材料分支独立读取中间 JSON，各实际 region 使用独立光栅，全部像素中心与网格共享毫米物理坐标系，允许 X/Y 像素物理间距不同。
原始 step profile 包围盒及基础 Px/Py 定义整板参考采样密度；局部采样不反向改变 region 或物性网格。
计算域、铜图案和相交钻孔分别扫描线处理，在区间或掩膜层组合：

```text
domain = step_profile AND layer_domain
copper_black = domain AND copper_pattern
dielectric_black = domain AND overlapping_drills
white = domain AND NOT black
```

介质起始铜图案为空。所有介质内 DRILL 投影统一作为材料 1 实心铜，记录 `drill_model=solid_copper`、`drill_scope=dielectric_only`。
铜层只使用自身图案；profile 的真实孔洞是域外几何，钻孔投影受 domain 限制。
DOCUMENT、COMPONENT 等非物理层以及尚无适用材料模型的层明确记录跳过原因。

## 深度与图案语义

DRILL 端点来自 matrix 的 START_NAME / END_NAME，JSON 保存递增铜层索引 `copper_span`。
介质与钻孔优先按铜层拓扑区间正长度相交判定，通孔、盲孔、埋孔使用相同规则。
需要 Z 时从起点铜层 start_mm 和终点铜层 end_mm 推导；必要跨度或端点 Z 不可用即报告错误。
仅铜层输入无需解析钻孔跨度。

介质缺少拓扑跨度时用推导 Z 判断，非零厚度采用半开区间，零厚度按所在平面是否到达判断；未知厚度回退发出 `equiv.drill_z_fallback`。
圆、长圆、方形、槽形和自定义孔形由 Parser 展开成投影多边形。采样直接使用该几何。
每个规整 Region 按岛孔嵌套求内部区间，不同 DRILL 集合按 OR 组合，重叠只计一次。

当前模型对金属化与非金属化 DRILL 统一使用实心铜，对孔壁、填孔及背钻采用相同投影近似。
ROUT 的真实挖空应在 profile / domain 中表达。同一钻孔层共享跨度，Z 内变化的孔径不在二维贯通模型中表达。

## 分辨率与容量

默认基础采样密度以原始整板长边 4096 像素定义，并保留物理长宽比。各 region 独立确定实际像素数，不把局部加密传播到其他 region。
自动模式按 region 内每轴网格数 n 与均匀单元边长 w 选择每单元样本数 `s=max(N+1,ceil(w/基础像素间距))`，局部像素数为 `n*s`。档位模式 N=8，专家模式 N=1；额外一个样本保留数值余量。局部像素边界与本 region 网格边界对齐。

显式 Px/Py 表示原始整板的基础采样密度和像素中心相位，各 region 只提取属于自身的连续行列窗口，不自动加密；不足则报错并提示增加 Px/Py。其边界不必对齐物性网格。
自动与显式模式均按像素中心及半开区间判断归属。每个输出单元都必须有有效采样，且所有采样中心必须位于本层域内。

数值掩膜按 region 生成、积分并释放，每个局部光栅最多 120,000,000 像素。诊断记录基础密度、各 region 的原点、像素间距和尺寸，以及二维 region 总像素数和最大局部像素数；总数不包含物理层重复采样。
容量阈值保证单元可采样；小走线、小孔是否捕获及物性是否收敛，仍由实际分辨率对照验证。

PNG 物性热图仅从 MaterialMap 按毫米坐标绘制。Python 参考版的整板黑白材料预览单独采样，长边最多 1400 像素，保持原始板范围、物理比例与域外标识；显示图不代表各 region 的数值采样分辨率，也不参与物性计算。

## 依据与实现对照

复杂材料图案通过扫描线区间逻辑组合，简单 profile 的几何布尔检查由几何分支负责。
逐 region 驻留字节掩膜，逐层预处理边并复用，局部采样筛选范围相交的完整轮廓，保留包围采样窗口的外环及孔洞关系；行前缀和与列累计复用同一物理采样行带的统计；不同 region 的局部索引不作为缓存身份，缓存按物理区间或像素区间区分。kx / ky 保留逐行 / 逐列公式。
缓存以本次几何、跨度和光栅配置区分，材料缓存与像素索引只服务采样。
公式见 [串并联推导](../../derivation/串并联PCB等效热模型推导.md)。

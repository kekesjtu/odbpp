# Rust 数值核心与 Python 可视化

## 产品边界

提供独立命令与分发包 `pcbkit-rust`、`pcbeq-rust`，保留 `pcbkit`、`pcbeq` Python 版本用于独立运行和数值对照。
解析器与等效器的组合不受语言版本限制，始终只通过当前中间 JSON 交接板数据。两个 Rust 包不互相依赖，也不读取对方内部对象。

## 语言职责

Rust 承担几何离散、整数布尔与扫掠、物理区间计算、扫描线材料采样和串并联物性积分等数值内核。
Python 承担文件与参数处理、Pydantic 契约、规划调度、几何约束和拓扑审计、诊断、发布及全部 SVG/HTML/PNG/Matplotlib 可视化。
region 的自适应细化、相邻合并和共享域验收保留 Python/Shapely 调度，竖条真实共同 Y 区间由 Rust 计算。Rust 核心版是混合语言产品，运行环境包含 Python。

Rust 经 PyO3 扩展以批量数据调用，Maturin 构建平台 wheel / sdist。共享 Rust 几何仅作为内部 crate 复用，不形成产品间运行依赖。
整数几何保持 1e-6 mm 坐标量化、显式岛孔和 NonZero 极性；输出精度仍由用户设置。几何算法间可有离散坐标和环排序差异，应以物理区域、拓扑、误差预算和物性容差验收。

## 运行与验收

后端选择只作用于一次调用的执行上下文，不修改全局模块函数。嵌套调用及异常退出恢复调用方上下文，Python 版无需安装 Rust 扩展。
Rust 版必须加载对应编译扩展；缺少扩展应明确失败，不静默退回 Python 数值计算。
网格几何仍独立于材料分辨率，采样不足、域外像素和资源超限沿用可定位诊断。数值核不导入绘图库，全部绘图消费既有 Python 数据模型。
两种核心均逐 region 独立划分均匀笛卡尔网格，不要求相邻 region 共形。每个 region 单轴最多一百万分格、整板最多五百万 XY 建模单元，单层自动光栅最多一亿两千万像素；资源超限报错，不更改物理尺寸或删减实体。实际核心身份与资源上限记录在运行诊断中。

共享验收用例分别运行两种后端；额外采用解析公式、固定随机图案、岛孔/重叠钻孔、缺采样、独立 CLI 与脱离源码目录的分发验证。
优化不得以整格铜面积比例代替逐行/逐列热导公式，也不得用较粗光栅改变几何。

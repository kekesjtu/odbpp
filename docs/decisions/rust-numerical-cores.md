# Rust 数值核心与 Python 可视化

## 产品边界

提供独立命令与分发包 `pcbkit-rust`、`pcbeq-rust`，保留 `pcbkit`、`pcbeq` Python 版本用于独立运行和数值对照。
解析器与等效器的组合不受语言版本限制，始终只通过当前中间 JSON 交接板数据。两个 Rust 包不互相依赖，也不读取对方内部对象。

## 语言职责

`pcbkit-rust` 使用 Rust 几何离散、整数布尔与扫掠内核，包内自带的 Python 模块承担其文件调度、契约与工程预览，直接调用本包扩展。
`pcbeq-rust` 从中间 JSON 读取开始，到 MaterialMap 文件关闭与发布为止，全部由 Rust 执行：Serde 输入校验、region 规划、局部网格、材料配置与采样、物性积分、几何验收和运行诊断均不得回调 Python。
Python 仅承担等效器命令启动和 MaterialMap 的 SVG/HTML/PNG/Matplotlib 可视化；图表不得重新读取中间 JSON 或重新计算物性。
region 的自适应细化、相邻合并、共享分区和验收均使用 Rust 调度。连续几何谓词通过 Rust 直接调用 GEOS C API，保留孔洞、连接、内接性和误差预算语义；不得以简化验收换取速度。GEOS 可来自 Shapely wheel 的原生库目录或 `PCBEQ_GEOS_LIBRARY`，计算流程不使用 Shapely Python API。
Python 参考等效器保留用于同输入、同物理约束的数值与性能对照。纯数值调用不导入绘图库，性能计时包含 JSON 读取校验至 MaterialMap 写入关闭，不包含图表和诊断报告序列化。

Rust 经 PyO3 扩展以批量数据调用，Maturin 构建平台 wheel / sdist。共享 Rust 几何仅作为内部 crate 复用，不形成产品间运行依赖。
整数几何保持 1e-6 mm 坐标量化、显式岛孔和 NonZero 极性；输出精度仍由用户设置。几何算法间可有离散坐标和环排序差异，应以物理区域、拓扑、误差预算和物性容差验收。

## 运行与验收

两条产品线分别拥有生产模块与依赖；Rust 入口不导入 Python 产品的源码，Python 产品没有 Rust 后端切换入口。Python 版无需安装 Rust 扩展。
Rust 版必须加载对应编译扩展；缺少扩展应明确失败，不静默退回 Python 数值计算。
网格几何仍独立于材料分辨率，采样不足、域外像素和资源超限沿用可定位诊断。数值核不导入绘图库，全部绘图消费既有 Python 数据模型。
两种核心均逐 region 独立划分均匀笛卡尔网格，不要求相邻 region 共形。每个 region 单轴最多一百万分格、整板最多五百万 XY 建模单元，每个 region 的局部光栅最多一亿两千万像素；资源超限报错，不更改物理尺寸或删减实体。实际核心身份与资源上限记录在运行诊断中。

两条产品线分别运行自身验收测试；额外采用解析公式、固定随机图案、岛孔/重叠钻孔、缺采样、独立 CLI 与脱离源码目录的分发验证。
优化不得以整格铜面积比例代替逐行/逐列热导公式，也不得用较粗光栅改变几何。

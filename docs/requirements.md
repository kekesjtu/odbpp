# ODB++ 解析与 PCB 物性等效需求

本文定义产品范围、物理约束和验收条件。产品边界、术语和数据流见[项目架构](architecture.md)。

## 单板解析与交付

- 支持 ODB++ v8.1 单板 step 的目录和压缩包输入。拼板重复与嵌套引用、T/B 图元不在范围内。解析器需支持基础标准符号及自定义符号递归展开。
- 按文件作用域解释坐标与一般尺寸，按 ODB++ 专用单位解释符号参数、resize 和钻孔尺寸。输出几何统一为毫米，并交付明确区分岛与孔的正向实体多边形。features/profile 记录解析及整层展开、合成由 Rust 完成，中间几何保存在 Rust 内部。
- 按[逐层轮廓与叠层](decisions/pcbkit/layer-profiles-and-stackup.md)交付整板与各层的实体范围、层图案、绝对 Z 及其可信状态。有层轮廓时，从层岛中扣除层孔与 step 孔的并集，保留伸出 step 岛的部分；缺失时取整板轮廓，存在但无法解析时报错并终止本轮导出，不回退到整板轮廓。
- 中间 JSON 仅交付 BOARD 层；MISC 层的目录、图案和关联信息不进入接口。MISC 使用独立绘图路线预览，不依赖整层多边形合成或中间 JSON。轮廓统一使用 profile 术语，按规整后的几何去重导出，层归属只记录在 profile 下。
- 解析器和等效器只通过[中间 JSON](interfaces/intermediate-json.md)交接板数据。入口须校验结构和必要物理语义。SVG/HTML 与可选逐层 PNG 用于工程核对，介质预览可在绘图副本中扣除相交钻孔。

## 几何与网格

- 以各层完整实体范围作为该层有效计算域，允许层伸出整板轮廓，不以整板实体范围裁剪或要求包含于其中。按有效几何对 profile 去重，同几何只划分一次并复用一致的 region；不同几何独立划分，不要求 region 跨层上下对齐。二维矩形与引用层的 Z 区间共同定义三维 region，缺失层不生成实体。
- 使用 FAST 式贪心矩形近似，在误差预算内尽量减少块数；允许向域外扩张，每个有效 profile 内矩形互不重叠。对各有效 profile 独立验收漏失与新增面积之和、独立实体、孔洞和正宽连接。面积达标不能豁免拓扑检查。诊断交付各有效 profile 的复用层数、二维 region 和网格数量、实际 XY 尺寸范围，以及原始与模型面积、漏失、新增、相对误差和三项拓扑检查。保护核心保留为内部约束，不写入诊断。策略和资源限制见[几何规划](decisions/pcbeq/geometry-planning.md)。
- 各 region 采用独立均匀的局部笛卡尔网格，单元完整属于一个 region 和一个物理层。常规输入提供粗、标准、细三个档位，专家输入只设置 X/Y 最大边长。网格保留真实短边，允许相邻 region 不共形，Z 方向为单层一格。
- 只改变 `--pixels-per-cell-axis N` 时，region 和网格坐标须保持不变。尺寸、近似误差或拓扑无法同时满足时，报告可定位的约束和失败原因。

## 材料与采样

- 等效 BOARD 上下文中的铜层与介质层，其他层不参与等效。铜层只用本层铜图案。介质层将到达该层的钻孔投影按实心铜处理；覆盖仅依据 matrix 层序和起止铜层，介质层须严格位于两个端点铜层之间。厚度和绝对 Z 不参与覆盖判断，外侧介质不被覆盖。钻孔不形成独立厚度层。中间 JSON 的介质实体范围仅由 `profiles` 交付，介质 `polygons` 只保存本层图元规整结果，无图元时为空，不填充轮廓基底。
- 每个物性单元沿 X、Y 各等分 N 份，在 N×N 个像素中心采样。`--pixels-per-cell-axis N` 接受正整数，默认 9，适用于所有网格档位和专家尺寸。矩形超出原始有效域的部分统一使用本层基底材料。局部光栅超出容量时报告所在 region。容量和覆盖规则见[材料采样](decisions/pcbeq/material-sampling.md)。
- 两相的热导率、密度与比热可逐字段配置，使用项目默认值时明确告警。面内热导可选择 2DVTN（`--mode 1`，默认）或 SPTRA（`--mode 2`）。Z 向热导与密度按体积分数加权，比热按质量加权。公式和配置见[材料模型](decisions/pcbeq/material-model.md)。

## 输出与验收

- [MaterialMap](interfaces/materialmap.md) 为每个有效单元交付三个方向的热导率、密度与比热容。物性适用于完整单元体积。采样覆盖率不能折减体积、质量或热容。中间 JSON 分别用 `null` 表达未知的层顶位置和层厚，任一项未知时 MaterialMap 的两个 Z 端点均为 `null`。
- 输入缺少有效域、缺少计算轮廓或必要钻孔跨度无法确定时，须报告可定位的错误。数值几何与物性由运行诊断支持核对。
- pcbeq 使用一个 `diagnostics.json` 记录运行诊断，不输出数值或图片产物清单。诊断分为几何统计、告警与错误、误差分析和性能分析。内置材料默认值记录告警，层厚度或累计绝对 Z 不可信记录非阻断错误，仍正常生成 MaterialMap。阻断失败须尽力发布本轮失败诊断，不将未完成统计写成零。
- 从正式 MaterialMap 恢复 region、网格和物性图表。原始轮廓与模型的面积差异及拓扑结果由数值诊断记录。图表用途与失败后的产物状态见[可视化](decisions/pcbeq/pcbeq-visualization.md)和[输出与发布](decisions/output-publication.md)。

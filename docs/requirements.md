# ODB++ 解析与 PCB 物性等效需求

本文定义产品范围、物理约束和验收条件。产品边界、术语和数据流见[项目架构](architecture.md)。

## 单板解析与交付

- 支持 ODB++ v8.1 单板 step 的目录和压缩包输入。拼板重复与嵌套引用、T/B 图元不在范围内。解析器需支持基础标准符号及自定义符号递归展开。
- 按文件作用域解释坐标与一般尺寸，按 ODB++ 专用单位解释符号参数、resize 和钻孔尺寸。输出几何统一为毫米，并交付明确区分岛与孔的正向实体多边形。
- 按[逐层轮廓与叠层](decisions/pcbkit/layer-domains-and-stackup.md)交付整板与各层的实体范围、层图案、绝对 Z 及其可信状态。层轮廓缺失时取整板轮廓，存在但无法解析时报告该层失败。
- 解析器和等效器只通过[中间 JSON](interfaces/intermediate-json.md)交接板数据。入口须校验结构和必要物理语义。SVG/HTML 用于工程核对，介质预览可在绘图副本中扣除相交钻孔。

## 几何与网格

- 以各层实体范围与整板实体范围的交集作为该层有效计算域。按有效几何对 profile 去重，同几何只划分一次并复用一致的 region；不同几何独立划分，不要求 region 跨层上下对齐。二维矩形与引用层的 Z 区间共同定义三维 region，缺失层不生成实体。
- 使用 FAST 式贪心矩形近似，在误差预算内尽量减少块数；允许向域外扩张，每个有效 profile 内矩形互不重叠。对各有效 profile 独立验收漏失与新增面积之和、独立实体、孔洞和正宽连接。面积达标不能豁免拓扑检查。诊断须记录原始面积、模型面积、漏失、新增、IoU、去重复用及约束结果。策略和资源限制见[几何规划](decisions/pcbeq/geometry-planning.md)。
- 各 region 采用独立均匀的局部笛卡尔网格，单元完整属于一个 region 和一个物理层。常规输入提供粗、标准、细三个档位，专家输入只设置 X/Y 最大边长。网格保留真实短边，允许相邻 region 不共形，Z 方向为单层一格。
- 只改变 `Px/Py` 时，region 和网格坐标须保持不变。尺寸、近似误差或拓扑无法同时满足时，报告可定位的约束和失败原因。

## 材料与采样

- 等效 BOARD 上下文中的铜层与介质层，其他层报告跳过原因。铜层只用本层铜图案。介质层将到达该层的钻孔投影按实心铜处理，钻孔覆盖优先按铜层跨度判定，介质层缺跨度时按 Z 判断。钻孔不形成独立厚度层，中间 JSON 的介质几何保留完整基底。
- 各 region 按毫米坐标独立采样，按像素中心归属单元。默认局部光栅可按需加密，显式密度保持整板参考像素间距和中心相位。矩形超出原始有效域的部分统一使用本层基底材料。样本不足时报告位置，不跳过单元。阈值和覆盖规则见[材料采样](decisions/pcbeq/material-sampling.md)。
- 两相的热导率、密度与比热可逐字段配置，使用项目默认值时明确告警。面内热导按逐行、逐列串并联计算，Z 向热导与密度按体积分数加权，比热按质量加权。公式和配置见[材料模型](decisions/pcbeq/material-model.md)。

## 输出与验收

- [MaterialMap](interfaces/materialmap.md) 为每个有效单元交付三个方向的热导率、密度与比热容。物性适用于完整单元体积。采样覆盖率不能折减体积、质量或热容。中间 JSON 可保存估算 Z，正式结果将不可信的 Z 标为未知。
- 待等效层解析失败、缺少有效域或必要钻孔跨度无法确定时，须报告可定位的错误。数值几何与物性由运行诊断支持核对。
- 从正式 MaterialMap 恢复 region、网格和物性图表。原始轮廓与模型的面积差异及拓扑结果由数值诊断记录。图表用途与失败后的产物状态见[可视化](decisions/pcbeq/pcbeq-visualization.md)和[输出与发布](decisions/output-publication.md)。

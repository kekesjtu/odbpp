# ODB++ 解析与 PCB 物性等效需求

本文件定义 pcbkit / pcbeq 的功能范围、物理约束和验收要求，开发方向以此为准。
协作与开发规范见 [AGENTS.md](../AGENTS.md)，实现约定和资料入口见 [项目文档](../README.md#文档索引)。

## 总体数据流结构

```text
[ ODB++ 压缩包/目录 ]
        │
        ▼
[ 1. ODB++ Parser：解析与拓扑规整 ]
        ├───────────────────────────┐
        ▼                           ▼
[ 2. 中间格式 .json ]     [ 3. 分层矢量预览 .svg/.html ]
        │
        ▼
[ 4. PCB 物性等效器 ]
        │
        ▼
[ 5. 等效结果 MaterialMap.json ]
```

中间 JSON 是解析器与等效器之间唯一的数据接口。SVG/HTML 只用于工程师交互式核对图层、走线、过孔、缩放及图层切换。

等效器内部采用两个独立分支：

```text
                     [ 中间 JSON ]
                       │       │
          几何建模分支  │       │ 材料采样分支
                       ▼       ▼
        [ 自动内接粗阶梯 region ] [ 逐层光栅化 ]
                       │       │
                       ▼       │
          [全局笛卡尔栅网格划分] │
                       │       │
                       └───┬───┘
                           ▼
                  [ 网格内像素统计与等效 ]
                           ▼
                  [ MaterialMap：完整单元物性 ]
```

region 是用于近似 PCB 板型的最小三维几何建模块；物性网格是 region 内赋予材料参数的最小计算单元。光栅用于快速采样材料图案，不能反过来决定 region 或网格的几何划分。

## 解析器约束

1. 仅解析代表单板实体物理结构的 Step，暂不处理拼板的矩阵重复排版与嵌套引用。
2. Parser 输出必须是完全正向（Positive）的实体多边形集合。岛和孔应有明确语义，不能要求等效器重新解释 ODB++ 图元极性。
3. 介质层基底按以下优先级确定：
   - 若 `steps/<step>/layers/<layer>/profile` 存在且有效，使用层级 profile；
   - 层级 profile 缺失时，回退到 `steps/<step>/profile`；
   - 层级 profile 存在但无法解析时，报告错误，不得静默回退；
   - 中间 JSON 保留未扣除 DRILL 投影的介质几何；穿透孔仅在 SVG/HTML 绘图副本中由相交钻孔投影扣除。铜层图案完全不受 DRILL 影响。
4. ODB++ 存在两套单位语义：
   - 坐标、一般尺寸按当前文件作用域中的 `MM` 或 `INCH` 解释；
   - 标准符号参数、resize 和钻孔尺寸等字段按规范指定的 µm 或 mil 解释；
   - Parser 输出的 JSON 一律统一换算为 mm。
5. 支持基础标准符号（r/s/rect/oval）的原生展开；自定义 `symbols/` 需递归读取其几何定义。
6. 暂不需要支持 T/B 图元。
7. 中间 JSON 必须为等效器明确提供每个待等效物理层的二维计算域、实体图案、Z 区间、厚度可信状态及其来源。铜图案多边形不能代替该层的计算域；板外区域不能被隐式当作 FR4。全项目保持唯一的当前 JSON 格式，不做 schema/generator 版本校验或兼容迁移；字段结构与必要物理语义须校验。解析器导出与等效器导入共用 Pydantic 模型，内部图元和计算结构保留 dataclass/数组；文本 `.schema` 从模型生成。
8. 待等效层的计算域优先取有效的层级 profile，缺失时取 step profile；存在但无法解析的层级 profile 必须报错。逐层计算域可以不同，例如刚挠结合板。等效器使用 step profile 确定整板范围，并使用逐层计算域规划该层真实存在的内接建模块；不能在几何块生成后仅凭部分覆盖率决定该层是否存在。

## 等效器输入与材料规则

1. 第一版对铜层及介质层进行物性等效。钻孔是跨层图案，不作为独立厚度层生成等效网格；DOCUMENT、COMPONENT 等非物理层不参与。其他材料层暂不套用铜/FR4 模型，须明确报告跳过原因。
2. 默认使用更密的材料采样光栅与 PNG 输出，并记录默认分辨率。用户可覆盖光栅像素数 `Px`与`Py` 表示整板 X、Y 方向各使用 `Px、Py` 个像素，即基础光栅尺寸为 `Px × Py`；允许 X、Y 像素在物理尺寸上不同。
3. 常规网格输入提供粗、标准、细三个档位，默认标准；档位的物理尺寸依据原始 PCB 范围、计算域及铜图案特征尺度自适应，须记录估算依据与最终尺寸，不能依据光栅或像素占比调节几何。专家只设置单元边长上限 `--max-cell-mm`，单位 mm，可提供一个值（同时约束 X/Y）或两个值（分别约束 X/Y），各方向须为有限正数；专家默认最大 5 mm。删除最小网格尺寸参数、约束、输出字段和相关冲突诊断；真实边界形成的短区间须保留。实际 `nx`、`ny` 仅作为派生结果输出。
4. 用户可提供热导率 `k1`、`k2`、两者的密度和比热容，单位均为标准单位。`1` 对应黑色铜区域，`2` 对应白色基底区域。允许为铜层和介质层分别配置或逐层覆盖；优先级为逐层配置、用户全局配置、项目默认值。
5. 缺少用户材料配置时，使用项目中明确记录数值和来源的铜/FR4 默认材料表，并发出明确警告；仍须正常生成结果。
6. 第一版仅将与介质层 Z 区间相交的钻孔投影视为**全铜、全黑**区域；铜层只依据自身铜图案，完全忽略 DRILL 投影。中间 JSON 的介质几何不扣除钻孔；介质采样以计算域内空铜图案为起点，将相交钻孔覆盖为黑色。不得把钻孔误当空气，也不得重复扣孔。结果须标注 `drill_model=solid_copper` 与 `drill_scope=dielectric_only`；需要介质采样的钻孔跨度无法确定时报告错误，不能擅自视为贯穿全板。仅铜层输入无需解析钻孔跨度。
7. 常规用户使用光栅分辨率、网格档位及材料配置；专家可以改用物性网格尺寸上限。region 仅采用真实 Y 区间竖条阶梯算法，遵守默认 3 mm 最大完整轮廓退缩量和 5% 最大面积损失比例，并检查内接性、孔洞和连接拓扑。程序优先细化超差最严重的位置，合并及 step/layer 共享分区后重新检查全部约束。完整轮廓检查覆盖外轮廓及孔洞，不把内部接缝算作轮廓，不使用仅顶点或 Y 向距离替代。内部策略、资源终止限及实际误差须有文档和输出记录。

## 内接三维建模块与物性网格

1. 根据完整 step profile 和逐层计算域自动形成轴对齐、内部互不重叠的竖条阶梯内接 region。直接使用竖条整个 X 区间内共同存在的真实 Y 区间，不进行 Y 取整，通过受约束相邻区间合并减少分区。二维矩形与所属物理层的绝对 Z 区间共同定义三维建模块，均须逼近实体板型。
2. 内接要求 region 完整位于相应原始实体计算域内，不得向板外扩张、跨越 profile 空洞，或在某层缺失的位置生成该层实体。允许在有明确误差预算的前提下省略普通边界的少量实体面积，必须记录原始面积、建模面积、损失面积/比例、内接检查、所用策略和局部细化情况；超出预算必须报错。
3. 不得丢失狭窄连接段、切断柔性连接段、删除独立实体或填平孔洞。在窄连接段、弯折和 profile 孔洞附近自动局部细化，直到内接性和拓扑保留检查通过，不能仅凭总面积或单个岛的保留面积判断连通性。保护的是 profile 的真实空洞/挖空；DRILL 投影仍按实心铜材料规则处理，不得误当几何空洞排除。
4. 采用竖条阶梯划分，避免不必要的碎片；全局网格传播造成的细分应明确统计。几何规划仅使用 JSON 中的物理坐标、计算域、拓扑及物理尺度/误差预算，可以考虑最大网格尺寸；不得读取或依据 `Px/Py`、像素间距、材料黑白掩膜、像素占比选择 region 尺度或边界。只修改 `Px/Py` 时，region 和物性网格坐标必须保持不变。
5. 所有 region 边界都是物性网格边界并必须保留，网格完全位于单个三维 region 内，不能跨 region 或物理层。采用全局笛卡尔栅：所有 region 的 X/Y 边界并入共同全局轴线；每个单元是相邻 X/Y 轴线构成的矩形，板外或缺失实体层不输出单元。按最大边长独立细分各轴线区间为最少数量的等宽单元：`n=max(1,ceil(L/max))`。短区间直接保留，不再有最小尺寸冲突或整数分格上下界无解的诊断；宽区域仍必须细分。
6. 尺寸约束、特征保护和内接几何不兼容时，报告具体特征、轴向、区间坐标、长度和约束并停止；不得删除连接段、合并不同的边界或静默放宽尺寸。几何网格先按物理尺寸确定，再检查光栅采样容量；默认光栅可在几何确定后加密以满足档位模式的最低采样容量，且必须记录；用户指定光栅不足时只能报错并提示提高分辨率或调整网格尺寸，不得自动改变 region/网格以迁就像素。专家模式至少要求每单元在两个轴向各有一个采样中心，单网格内无像素时必须报错。
7. 各物理层采用共同的 XY 划分基础；逐层计算域不同的位置必须在几何规划阶段明确分区和层存在性，保证输出的每个三维 region 与网格在所属层内是完整实体。不能用部分覆盖单元替代刚挠板的逐层建模块。一个二维 region 标识与物理层/Z 区间共同唯一确定三维块。
8. 提供 region 几何诊断图，使用等效器实际采用的内接矩形集合，逐 region 显示边界、面积色标及编号/尺寸表；对照原始轮廓并统计分区数、短边分布、损失面积、孔洞和连接段保留情况。几何诊断图与物性网格热图必须明确区分。

## 独立光栅化与材料采样

1. 材料采样分支独立读取同一中间 JSON，按整板范围和用户 `Px/Py` 逐层生成计算域、铜图案及相交钻孔的掩膜。范围不能由内接后可能缩小的 region 包围盒重新定义；光栅分辨率只控制材料采样误差、速度和内存。
2. 解析器负责必要的图元极性和拓扑规整。等效器不再对复杂铜图案和钻孔多边形反复做 union/intersection/difference，应分别光栅化后用像素或扫描线区间逻辑组合：铜层有效黑色为 `计算域 AND 铜图案`，介质层有效黑色为 `计算域 AND 相交钻孔`，有效白色为 `计算域 AND NOT 有效黑色`；介质层初始铜图案为空。几何分支对简单 profile 的必要检查与复杂材料图案布尔运算应明确区分。
3. 光栅化正确处理岛、孔、嵌套与钻孔覆盖，不依赖绘制顺序。逐层或分块处理，避免同时驻留全部图层；几何验证不能被低分辨率光栅中的“看起来连通/无孔”替代。
4. 像素归属网格按中心/索引及半开区间判断，像素边界不要求对齐物性网格边界。档位模式应保证每个单元各轴向有足够采样中心（明确记录内部阈值）；专家模式每个输出网格必须有有效采样；不足或与几何存在性矛盾时给出可定位诊断，不静默省略建模单元、填充 FR4 或赋予零物性。
5. 使用行、列累计统计等方式加速采样积分；`kx/ky` 必须保留逐行/逐列串并联公式，不能仅用整个网格的铜面积比例代替。可复用相同计算域、钻孔掩膜或材料采样缓存，但缓存必须区分几何输入、层跨度和光栅配置，不得让缓存反向影响几何划分。

## 等效公式与输出

1. 采用 [密度和热容推导](derivation/密度和热容等效热模型推导.md) 和[串并联热模型推导](derivation/串并联PCB等效热模型推导.md) 中的两材料、层内图案沿厚度贯通、正交各向异性串并联近似。每个有效网格单元输出 `kx`、`ky`、`kz`、`density`、`specific_heat`：
   - X 方向：每一像素行内沿 X 串联，各行并联；
   - Y 方向：每一像素列内沿 Y 串联，各列并联；
   - Z 方向：各像素柱并联，即按黑白面积分数加权平均；
   - 密度：体积分数加权；
   - 热容：质量加权。
2. 同一物理层内部不再沿 Z 切分；一个等效网格单元在 Z 方向完整对应所属物理层。不得将跨越两个物理层的体积合并为同一个等效单元。
   MaterialMap 单个层级 JSON 的每个 region 记录层身份、XYZ 最小/最大边界（未知 Z 为 null）及 XY 网格线；单元按 Y 外层、X 内层的行主序仅记录 kx/ky/kz/density/specific_heat，不导出单元索引、面积和采样统计。每个单元物性条目必须对应完整的三维建模网格并赋予其全部物性，密度和比热适用于该单元的完整体积。不能把网格按完整实体建模，却用部分计算域覆盖率缩减其质量/热容；不能通过有效像素归一化掩盖几何块越出计算域。采样覆盖率可以作为质量诊断，但不能作为建模体积的乘数。原轮廓到内接模型的面积损失应独立记录。
3. 输出文件格式参考 [MaterialMap 参考文件](reference/Flotherm_reference_MaterialMap.csv)。不要求完全一致或 Flotherm 可以导入，并且尽量不要完全相同以规避版权问题。应该**参考后自己设计**。
4. 输入 JSON 存在待等效层解析失败、缺少有效计算域或无法确定必要钻孔跨度时，等效器必须给出可定位的诊断，不得静默生成。

## 叠层、厚度与格式补充

1. ODB++ 的 copper weight 随当前单位制改变物理含义：
   - `UNITS=INCH`：单位为 oz/ft²，属于面密度；
   - `UNITS=MM`：单位为 µm，属于铜厚度。
2. 官方规范中的 `.layer_dielectric` 仅用于非铜层：DIELECTRIC、SOLDERMASK、SOLDER PASTE。
3. 中间 JSON 与 SVG/HTML 预览中，板内且有实体的物理层必须给出绝对 Z 起止（mm，自叠层顶面向下）；厚度数据缺失时给出 best-effort 位置并显式标记 `thickness_known=false`，不得静默当作实测值。DRILL 在中间 JSON 中只以投影多边形和 `copper_span` 表达几何/深度，不导出可由端点铜层推导的 `z_mm`。
4. 英制 `.copper_weight` 按内置默认铜密度 8.96 g/cm³ 换算厚度，用于绝对 Z；输出需记录 `thickness_source` 与 `assumed_density_g_cm3`，且保留 `kind`/`unit` 以区分物理量。

# 5% 内接预算与 Viewer 交互优化（2026-10-03）

用户允许损失 5% 板型面积，并要求减少 Y 上下边界不同的细碎竖条。
`rectify.py` 的 v3 策略使用整板短边估算初始尺度、公共 Y 基础向内量化，
以及受预算约束的相邻截面合并。每个候选仍检查内接性、岛/孔对应、
正宽连接和局部几何核保留；不通过时拒绝合并。5% 适用于每个有效层域，
共享 step/layer 分区后再次核查。光栅分辨率不进入此流程。

## 同一标准档位的几何比较

基线 `9559b86`，每次测量为独立进程。峰值内存含输入 JSON 和 Python
运行时；耗时为几何规划与网格生成，不含 JSON 加载和 PNG 写盘。

| 案例 | region 前→后 | Y 强制轴线前→后 | XY 单元前→后 | 新板型损失 | 几何秒前→后 | 峰值 MiB 前→后 |
|---|---:|---:|---:|---:|---:|---:|
| 刚挠板 | 287→45 | 125→43 | 15354→4262 | 4.985% | 1.996→1.708 | 403.75→403.36 |
| kitchen-sink | 450→78 | 282→62 | 61092→4217 | 4.997% | 0.373→0.257 | 67.14→44.11 |
| video | 26→6 | 23→5 | 5069→3441 | 4.927% | 0.359→0.345 | 171.25→171.29 |

运行时间受本机负载影响，数据不是性能承诺。默认尺度不是最少矩形数的全局
最优解；特征附近仍可能需要密集轴线，不能为了轴线均匀删除真实几何特征。

## 材料采样核查

三个真实案例的默认光栅与 X/Y 都加倍的光栅具有完全相同的 region、网格坐标
和单元顺序。三档网格均能规划；默认材料警告、solid_copper 钻孔规则保留。
详细相对误差、耗时与峰值内存见
[coarse-region-validation.json](../equivalence/coarse-region-validation.json)。

默认→加倍的 kx/ky 第 95 百分位相对差异：刚挠板约 12.36%/11.53%，
kitchen-sink 约 1.15%/1.06%，video 约 14.51%/12.37%。个别细走线、
小钻孔以及接近纯 FR4 的单元有更大的相对误差。因此“每轴至少 8 个采样中心”
只说明采样容量合格，不能保证任意细铜图案已经收敛；需要更高 Px/Py 时保持
几何固定。板型面积损失与这些材料采样误差分别记录。

```powershell
uv run --all-extras python tools/validate_coarse_regions.py --baseline-ref 9559b86
uv run --all-extras python tools/sync_out.py --grid-level standard --force-equivalent
uv run --all-extras python tools/validate_architecture.py --audit-out
uv run --all-extras python -m pytest
```

## 前端与解析检查

参考已安装 Viewer 的实际 UI，增加板框/层域、层叠矩阵、搜索、双击隔离、
选中层定位、板框导航和两点测距。解析后的 `FeatureFile.histogram()` 将
图元类型、原始极性、符号和有效单位作用域分组，供属性查询使用。
这些统计明确标为规整前的输入记录，不能反向用作正向实体面积或等效输入。
JSON 的 preview-2 和 CSV 的 materialmap-5 实体语义不变，没有扩展中间接口。

修正两个坐标缺陷：鼠标读数和测距从含 Y 翻转的组逆变换回真实 mm；缩放按钮
使用画布实际屏幕中心，包含侧栏造成的偏移。属性使用 DOM textContent，避免
层名等输入被当作 HTML。窄窗口采用上下布局，确保板图有可用的显示空间。

浏览器验证了单击选择不改变可见性、双击隔离、搜索仅过滤列表、层域叠加、
矩阵和选中层定位。窄视口两点间隔 100 屏幕像素的预期距离为 19.994417 mm，
实测显示 ΔX=19.994、ΔY=0.000、距离=19.994 mm；浏览器未报告脚本错误。
18 份最终案例 CSV 均通过完整层域/region/全局轴线/尺寸/Z/物性界限核查。

Viewer 调研和观察边界见 [10-viewer-ui-workflow.md](../research/10-viewer-ui-workflow.md)。

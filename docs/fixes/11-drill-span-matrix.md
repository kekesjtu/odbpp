# 层叠矩阵钻孔跨度箭头

矩阵最左侧显示钻孔层的竖直箭头：起点横帽与 START_NAME 对应层行中心对齐，
箭头与 END_NAME 对应层行中心对齐。按原始 matrix 行号排列层，名称匹配忽略大小写；
保留作者声明的起止方向，不使用 Z 厚度值或钻孔名称猜测跨度。即使厚度未知、
各层 Z 暂时相同，仍可核对明确声明的起止层。

跨度重叠时分配不同箭头列，互不重叠的跨度可共用一列。点击矩阵 drill 行、
左侧图层列表中的 drill 或跨度箭头后，对应箭头变红，起止层名称同时高亮，
矩阵上方显示完整钻孔名称和起止层。选择其他层时取消箭头高亮。
点击选择不改变图层可见性，Enter/空格也可选择矩阵行与箭头。

箭头根据实际行高定位，并在矩阵打开和表格大小变化时更新，支持文本换行、
滚动和窄窗口。无法唯一匹配的端点不画箭头，在钻孔跨度列和选择说明中标明
“跨度未解析”，不会擅自假定为通孔。此改动使用现有 preview-2 元数据，
不改变解析器、中间 JSON、region、网格或物性结果。

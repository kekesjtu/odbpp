# 12 · Heatmap 阅读布局

2026-10-05。原热图默认宽 4384 px，却在最大宽 1100 px 的页面内整体缩放。
三个方向连同小号字体、单位、Z 和色标一起缩小，图层多时材料掩膜又占用大量纵向空间。

## 修改

- 保留 `heatmaps/<layer>.png` 三方向总览，新增 `heatmaps/directions/<layer>.kx.png`、
  `.ky.png`、`.kz.png`。独立图复制总览的实际面板像素，不重复积分、聚合或插值。
- 页面最大宽度增加至 1600 px，方向卡片采用自适应 CSS grid，最小目标宽度 420 px；
  小于该宽度的屏幕使用一列。点击图像可打开原 PNG，总览保留独立链接。
- 材料掩膜默认折叠，展开后可点击查看原图；图像使用延迟加载。
- PNG 字号按面板宽度自适应，原 `font_scale` 作为最小字号；标题、单位、色标和
  子图之间增加留白。狭长板的元数据换行，不改变实际板型比例。
- 色标保留三方向共享范围，空间充足时增加中值；均匀层显示与数据相同的单色条。
- `sync_out.py` 检查独立 PNG 的完整性，并清理已失效层的独立图。

## 验证

```powershell
uv sync --all-extras
uv run --all-extras python -m pytest tests/test_visualize.py tests/test_sync_out.py
```

48 项通过。已有测试继续验证图型比例、方向、无层区域、共享色标、网格边界及层名碰撞。
补充验证独立图与总览对应位置的颜色一致、均匀层色条一致、页面独立图链接、
缺少独立图时拒绝复用以及失效独立图的清理。

更新 `out/` 中 18 组结果，共 81 个物理层（81 张总览、243 张独立方向图），
最终重绘耗时 16.60 s。逐文件哈希核对确认 CSV 和 meta 完全不变，
所有图例页本地图片及链接目标存在。人工查看刚挠板独立方向 PNG，核对字体、色标、
面板留白与板型比例。region、网格、材料采样和等效公式未修改。

输出目录按现有规则不纳入 Git；后续 `heatmap` 或 `equivalent` 命令均使用新版布局。

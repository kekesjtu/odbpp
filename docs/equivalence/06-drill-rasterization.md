# 06 · 当前过孔/钻孔的光栅化处理

本说明对应当前代码，描述已实现的行为。钻孔是跨层图案，
不生成独立厚度层。材料规则记录为 `drill_model=solid_copper`、`drill_scope=dielectric_only`：仅在覆盖的介质层
内，整个钻孔实体投影使用材料 1（默认铜），不是空气，也不是只保留镀铜孔壁。

## 不同深度形式

| 形式 | 当前覆盖规则 |
|---|---|
| 通孔 | DRILL 层起止为最外侧两铜层时，只投影至跨度内介质层，铜层不受影响 |
| 盲孔 | 一个端点为外侧铜层，另一个为内层；只覆盖该跨度内的介质层，铜层不受影响 |
| 埋孔 | 两端均为内层铜层；只覆盖内层跨度内的介质层 |
| 相邻层微孔、堆叠微孔 | 分别按各 DRILL 层的端点跨度处理；同一物理层上的多个投影做 OR |
| 起止铜层无法解析 | 不猜测为通孔；解析器报告未知跨度，等效器在需要介质采样时拒绝正式输出；仅铜层输入不需要该跨度 |

深度来自 matrix 的 `START_NAME/END_NAME`，不是按层名中含有 via、blind 等字样判断。
解析器将起止层解析为自上而下的铜层索引，并提供绝对 Z。例：四铜层 C1–C4，
C1→C2 钻孔只覆盖 C1/C2 之间的介质；所有铜层及 C2 下方介质不受投影影响。

等效器优先用 `copper_span` 判定：介质层的铜层间隔
必须与钻孔跨度有正长度交集。这样即便未知铜厚导致不同铜层的 best-effort Z
重合，也不会凭相同 Z 把盲孔错误扩展到别的铜层。

外部 JSON 若没有铜层跨度索引，当前代码回退为绝对 Z 相交判断；非零厚度层
采用半开区间相交，零厚度层按所在平面是否被钻孔到达判断。该路径在层厚未知
时发出 `equiv.drill_z_fallback` 警告，精度不如完整跨度索引。钻孔 Z 区间本身
无法确定时仍然报错。项目自身的规范解析结果应保留铜层跨度索引。

## 不同二维形状

| 输入形式 | 进入光栅化前的几何 |
|---|---|
| 圆孔 | 标准圆符号展开为圆盘多边形；圆弧先按物理弦高容差离散 |
| 椭圆/长圆孔 | oval 或相应自定义符号展开、旋转/镜像/平移后形成实体多边形 |
| DRILL 层内槽形/路径图元 | 已支持的 L/A 图元按符号沿线段/圆弧扫掠，形成槽形投影 |
| 方形、矩形、自定义孔形 | 使用相应标准符号或递归自定义 symbols 几何，最终仍为正向多边形集合 |
| 单独 ROUT 层的铣槽 | 当前不作为 DRILL 投影，等效器报告跳过；真实几何挖空须在 profile/domain 中表达 |

二维尺寸来自已展开的 features 符号及几何。等效器不重新用 tools 中的
finish_size/drill_size 修改孔径；圆弧默认弦高容差为 0.005 mm，export 坐标默认
保留四位毫米小数。毫米坐标和符号尺寸按各自单位语义在 Parser 中统一换算。
解析器已处理正负极性和岛/孔；等效器不按图元绘制顺序重新解释极性。

同一钻孔层的所有图元共享该层的起止跨度。不同跨度必须在输入中由不同钻孔层
表达；聚合后的 JSON 不是逐孔制造工艺模型。

## 扫描线和掩膜逻辑

1. 在原始 step profile 的包围盒内建立 Px×Py 光栅，像素中心为采样点。
2. 铜层只扫描计算域和自身铜图案；介质层扫描计算域和相交 DRILL 多边形。
3. 每个像素行求多边形内部区间；岛、孔和嵌套由规整边界的 even-odd 截面处理。
   介质内不同钻孔集合的区间做 OR；铜层只使用自身图案，重叠不会抵消，也不会重复计算材料。
4. 铜层 `黑色 = step域 AND layer域 AND 铜图案`；
   介质层 `黑色 = step域 AND layer域 AND 相交钻孔`。
   域内其余为白色基底；域外为灰色，无物理层实体。介质层初始铜图案为空。
5. 像素中心按半开区间归属物性单元；根据行/列黑像素统计计算 kx/ky，
   根据面积分数计算 kz、密度和质量加权比热。没有孔的独立 Z 厚度层。

Parser 的介质实体多边形与计算域均保留未扣除 DRILL 的几何。
SVG/HTML 只在绘图副本中扣孔；等效器以空铜图案加 DRILL 覆盖形成介质掩膜，
不进行材料多边形 difference，也不把钻孔当空气。铜图案内已有避空区不会被 DRILL 填黑。profile 的真实孔洞/挖空则保留为几何空域，
即使 DRILL 与之重叠也受计算域 AND 限制，不会越域填铜。

## 当前简化与能力边界

- PLATED、VIA、NON_PLATED 工具类型可被原始解析模型读取，但聚合 JSON 与
  当前等效器没有逐孔按工具类型选择材料的分支。所有介质内 DRILL 投影统一实心铜；
  **非金属化孔（NPTH）目前也按此规则处理**，不会成为空气孔。
- 空心镀铜孔、填铜/树脂填孔、封孔、孔壁厚度未分别建模。
- 微孔即使为锥形，也使用同一 XY 投影覆盖跨度内介质层；不描述沿 Z 变化的孔径。
- 背钻没有专门的去铜模型；若被表达为 DRILL 层，仍是该跨度内介质的实心铜覆盖。
- 光栅没有抗锯齿或分数像素覆盖。小孔若没有任何像素中心落入，可能完全漏采。
  档位要求每个物性单元至少 8 个采样中心/轴，仅保护单元容量，不能保证每个小孔
  都有采样或已经收敛；提高 Px/Py 才改善材料采样，不能通过加密显示 PNG 补救。

实现入口：`stackup.py::drill_span`、`expand.py::record_region`、
`equiv.py::_collect_drills/_topological_overlap/_evaluate_layer`、
`raster.py::RasterAxis/LayerMask`。测试涵盖铜层独立性及介质钻孔覆盖、跨度外不投影、
未知跨度失败、未知厚度时的介质拓扑匹配，以及嵌套岛孔与重叠投影的掩膜一致性。

# 04 · v3 单元尺寸约束修复的历史记录（2026-09-30）

以下是 materialmap-3 的历史测量，不是当前架构。其像素驱动矩形化、
全局网格线传播和部分覆盖语义已由 [v4 内接架构](05-inscribed-architecture.md)
替换。当前 region 数、内接面积和性能见修复 09 与 architecture-validation.json。

## 修改结果

等效器与同步工具移除 `--nx`、`--ny`、`--coarse-grid` 输入，改用
`--min-cell-mm`、`--max-cell-mm`，默认 0.1 / 5 mm。各参数传一个值时
同时约束 X/Y，两个值时依次约束 X、Y。`nx/ny` 保留为派生的输出数量。
AGENTS 的材料输入、矩形化/网格规则和验证要求已同步修改。

所有 region 边界仍是强制网格线。长度 L 的相邻强制线区间选择最小可行整数 n：

```text
ceil(L/max) ≤ n ≤ floor(L/min)
每个单元长度 = L/n
```

例如 L=64.52325 mm、max=5 mm，需要 13 列，各列约 4.96333 mm。
边缘有多少强制线都不会消耗这个细分所需的“格数预算”，因为已取消整板格数输入。

长度短于 min、或整数分格无解时，报告 `grid.size_incompatible`，给出轴向、
区间坐标、长度及尺寸范围。无法为每个单元提供光栅像素中心时报
`grid.cell_without_pixel`。不删除 region 边界或放宽尺寸上下限。
对极小尺寸输入先检查像素容量，避免尝试创建超大网格。

meta 升级为 `odbpp/materialmap-3`，记录 `size_constraints_mm`、
`actual_edge_range_mm` 和实际网格线。CSV 列布局保持不变，热图仍直接读取 CSV。
复用缓存时必须匹配新 schema 与各轴上下限；旧结果不能误复用。

## region 分区图与统计

新工具 `tools/plot_regions.py` 使用与等效器完全相同的矩形化函数，
输出到 `out/<case>/regions/`：

- `regions.png`：整板、两端放大图及短边直方图。
- `regions.svg`：可缩放；悬停显示 region 编号、尺寸、面积。
- `regions.csv`：全部 region 的编号、边界、长宽和面积。
- `regions.stats.json`：矩形化来源、面积误差与尺寸统计。

颜色表示面积，使用对数色标；黑线是 region 边界，红虚线是原轮廓。
分区图没有添加等效网格线，避免混淆两个层级的划分。

| 样例 | region 数 | 最短边 | 短边 < 1 mm 的 region | 面积 min / median / max（mm²） |
|---|---:|---:|---:|---:|
| `designodb-rigidflex.tgz`（含柔性连接段和刚性主体） | 63 | 0.81675 mm | 43 | 2.001 / 8.005 / 2793.066 |
| `kicad-kitchen-sink`（复杂异形板对照） | 198 | 1.1155 mm | 0 | 1.244 / 87.104 / 873.527 |

**结论：存在局部密集和细长的 region。** 当前矩形化沿 X 扫描轮廓，
截面变化时形成新的矩形列，曲线、斜边与孔洞附近尤其明显。
刚挠板较小矩形集中在柔性段弯折和主体边缘，中间则是一个大矩形。
复杂异形板的长斜边会生成更多条状 region。

这些图不能单独证明精度应当降低：是否“过密”还取决于窄实体和孔洞的保留要求、
允许的面积误差及计算代价。本次保持原矩形化精度，解决的是宽区域没有网格细分的问题。

批量验证还发现了同一阶梯端点因浮点表达式不同而出现约 10⁻¹⁴ mm 的差异。
现已让左右区间用同一表达式计算共享端点，消除虚假的零宽间隙；
没有合并不同的物理边界。异形板真实强制 X 线为 161 条，Y 线为 128 条。

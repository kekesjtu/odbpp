# 内接建模块与独立材料采样（2026-09-30）

本版本用完整实体网格取代部分覆盖单元。中间接口仍为
`odbpp/preview-2`：其层域、正向材料多边形、绝对 Z 和厚度来源已足够。
输出升级为 `odbpp/materialmap-5`；旧 v2/v3/v4 的覆盖率质量语义不能沿用。

## 两个独立分支

几何分支仅使用 step profile、逐层 domain、物理毫米坐标和内部策略。
材料分支独立读取相同 JSON，用原始 step profile 的包围盒和默认或用户指定的 Px/Py
建立光栅。光栅范围不会随内接损失缩小。几何规划完成后检查采样容量；
容量不足报错，保留已规划的几何坐标供诊断。

region 是实体几何块：二维内接矩形、物理层名和该层完整绝对 Z 区间共同
定义三维块。网格是 region 内的物性计算块，同一层不沿 Z 分割。
一个二维 region 可对应不同层的不同 Z；逐层存在性在几何规划时确定。

## 内部策略和误差预算

策略标识为 `inscribed-vertical-staircase-v3`（2026-10-03 更新）。

1. 轴对齐轮廓先按真实顶点生成精确条带。斜边、圆弧的初始物理尺度
   为 `max(0.5 mm, 整板短边 / 32)`；同一 step 的层域使用共同 X 基础及 Y 原点。
2. 每个条带取跨越的全部顶点事件和边界极限的共同实体截面。边在事件之间
   线性变化；取共同截面并向内量化 Y，形成保守内接阶梯。
3. 优先减少向整板传播的 X/Y 强制轴线，其次减少 region 数。先尝试同一
   物理 Y 基础上的 0.5/1/2/4/8 倍初始尺度向内量化；过窄截面保持精细边界。
   再对相邻竖条取共同截面，统一上下边界后合并；每一批次接受前检查面积、
   内接与矢量拓扑，失败则逐个核查并拒绝破坏特征的合并。矩形互不重叠。
4. 默认面积损失预算为原始有效域面积的 **5%**，小板也遵守该比例。
   绝对面积下限默认关闭；隐藏诊断接口仍可显式覆盖。预算不随周长放宽，
   也不读取像素间距。允许以该预算削减普通边界细碎变化，不删除连接和孔洞。
5. 面积或拓扑不通过时，只细化存在边界损失的条带，每次减半，最小内部
   尺度 0.0625 mm、最多八轮。内接、面积、拓扑仍不通过必须失败。
   最小内部尺度是几何策略的终止限，不能保证任意小特征均有解。
6. 原域与模型检查组件一一对应、孔洞一一对应、孔洞不连通至板外及
   正宽连接；另以 0.03125/0.1/0.25/0.5/1 mm 几何腐蚀检查每个局部实体核
   的保留，防止同一岛内的小叶片/窄颈附近实体被总面积检查掩盖。
   检查使用矢量几何，不使用材料掩膜。

上述尺度与预算写入 metadata，并记录各轮条带数、损失面积、拓扑结果，
以及 `coarsening` 中的公共 Y 尺度、简化前后轴线评分、合并次数和拓扑拒绝次数。
内接面积数值检查允许 1e-8 mm² 浮点容差，Parser 的 Clipper 坐标量化为
1e-6 mm；这不是向板外扩张的物理误差预算。

层域的有效物理实体为原始 layer profile 与原始 step profile 的交集。
刚挠真实案例部分 layer profile 比 step 略大且不包含 step 的一个真实孔洞：
交集使全板真实孔洞仍被保留。metadata 同时记录 authored_area、
outside_step_area、effective_domain、有效域的模型损失，避免把层域不一致
混入阶梯误差。重复层域只规划一次，不按材料图案或像素缓存几何。

不同层的模型矩形局部叠加分区，所有物理层共享 region 标识及 XY 基础。
每个域明确列出 `domain_region_ids`，整块存在或整块不存在；
禁止用部分覆盖率决定层存在性。共享分区再次检查非重叠与完整域覆盖。

## 全局笛卡尔栅、档位与专家尺寸

所有 region 的 X/Y 起止坐标组成强制轴线；各相邻轴线区间按物理尺寸
细分为最少数量的等宽单元：`ceil(L/max) ≤ n ≤ floor(L/min)`。
轴线贯穿整板，各物理层使用同一组轴线。板外及缺失层域不输出单元。
每个单元完全位于单个 region 内，并完整对应所属层的绝对 Z 区间。
`cell_i/j` 是全局轴线索引，四个边界对应 `x_lines[i:i+2]`、
`y_lines[j:j+2]`；nx/ny 是实际全局轴向间隔数，不作为输入。
局部细节传播会增加中央实体的格数，metadata 记录轴线数和实际单元数。

常规输入 `--grid-level coarse|standard|fine`，默认 standard。
档位先按原始整板尺度与正向铜图案估算物理尺寸，再生成全局网格：

- 铜图案每个正向多边形的 `2A/P` 是细长图案的近似宽度；记录其最小值，
  取不小于 0.01 mm 的估计值中第 10 百分位作为代表值。它不是严格最小线宽，
  环孔、网络形状和离散边缘会影响它。被过滤的估计数量也写入输出；过滤只
  影响档位建议，不删除任何铜图案或 profile 特征。
- 粗/标准/细的整板尺度分母分别为 32/64/128，特征宽度乘数为 24/12/6。
  最大单元目标为两者较小值，再以整板最长边/512 设置计算成本下限。
- 各轴最小尺寸取该轴最小强制区间的一半与最大目标的四分之一中较小值。
  该规则只依赖矢量几何，使全局边界可保留；档位依据、上下限及实际尺寸
  范围均记录在 `grid.mesh_configuration`。

专家给出 `--min-cell-mm` 或 `--max-cell-mm` 即进入专家模式；未指定的一项
采用 0.1/5 mm。各参数接受一个值或 X/Y 两个值，不能与显式档位混用。
整数分格、强制边界或特征保护无解时报告轴向、区间、长度和约束，停止；
不合并边界、不删除特征、不放宽专家最小尺寸。
单轴区间超过一百万分格报几何资源错误，独立于光栅配置。

默认材料光栅长边至少 4096 像素，保留物理长宽比。网格先确定，采样分支
随后按最小实际单元加密光栅：档位每个轴向至少 8 个采样中心，专家至少 1 个。
默认按每个最小区间预留额外一个样本以避免像素相位差，最多 1.2 亿像素；
超出预算明确报错。显式 `--px/--py` 必须一起提供，分辨率不足直接报错，
保留既定几何。任何情况下均不得用像素数改变 region 或网格。

默认掩膜 PNG 的显示长边目标从 700 提至 1400 像素；热图面板宽从 720
提至 1440 像素。显示图可能重采样，内部原始光栅参数以 meta 为准。
旧几何调参和部分覆盖告警选项退役，仅保留隐藏的内部诊断选项。

## 独立掩膜与物性

铜图案、计算域及各相交钻孔分别扫描线光栅化。材料组合用区间逻辑：

铜层 `black = step_domain AND layer_domain AND copper`；
介质层 `black = step_domain AND layer_domain AND drills`。

介质初始 copper 为空，仅介质内钻孔覆盖为 solid_copper，且不生成独立厚度层。
每个输入 Region 使用其已规整的岛孔语义；不同铜/钻孔 Region 之间作 OR，
防止 even-odd 把材料重叠抵消。材料分支不对复杂多边形重复 union、
intersection 或 difference。简单 profile 的几何检查是独立的必要操作。

每次仅驻留一个层的字节掩膜；同一全局 Y 带用 NumPy 行前缀和、列累计计算黑像素比例，避免每个
细分单元重复扫描整块材料。
每像素中心按半开单元区间归属。完整内接单元应有全部域内样本；
无样本或出现域外样本，报告层、region、单元坐标并失败，不归一化掩盖。

kx 逐行串联、行间并联；ky 逐列串联、列间并联；kz 按黑白面积分数并联。
密度按体积分数加权，比热按质量加权。两份推导文档是公式来源。

MaterialMap 的五个物性适用于每行的完整三维体积：

`V = (x1-x0)(y1-y0)(z_end-z_start) × 1e-9 m³`，
`mass = density × V`，`heat_capacity = mass × specific_heat`。

兼容保留 domain_area_mm2/domain_coverage/partial_domain 列，但新语义恒为
cell_area_mm2/1/false。不能将覆盖率再乘入质量或热容。
原轮廓到内接实体的面积损失单独记录。厚度未知仍传递 best-effort 绝对 Z，
thickness_known=false 及来源，不能当成实测厚度。

材料优先级为逐层覆盖、全局层类型配置、用户全局配置、项目默认。
`layer_types.copper` 和 `layer_types.dielectric` 分别接受 copper/base 两相
配置；每相字段为 k_w_mk、density_kg_m3、specific_heat_j_kgk。
默认铜为 385 W/(m·K)、8960 kg/m³、385 J/(kg·K)（项目记录 CRC 典型值）；
默认 FR4 为 0.3、1850、1100（项目记录 Isola 370HR 等典型值）。
默认值使用明确警告并在 metadata 记录每字段来源。

## 诊断、复用与限制

sync_out 从最终 metadata 的实际矩形画 region 图，输出边界、编号/尺寸表、
面积对数色标、短边直方图、原始轮廓及损失/拓扑检查。
逐层热图直接画最终 CSV 的实际全局单元，每层一张 kx/ky/kz 图。
掩膜图片为保物理长宽比的显示重采样；收敛检查直接使用内部原始光栅统计，
不从显示 PNG 反推数据。

批量结果复用要求 source、当前字段结构、Px/Py、尺寸配置、图片配置、
全部输出和 pipeline_fingerprint 一致；指纹包含几何、采样、材料与热图代码。
改变 Px/Py 可重算材料，但 region/grid 的原始浮点坐标必须完全相同。
任何待等效层失败或介质采样需要的钻孔跨度未知都阻止正式结果写入；仅铜层输入忽略 DRILL。

当前是二维两相、层内贯通的串并联近似；不含空气钻孔、镀铜薄壁、
Z 内细分或真实三维细走线导热。内部几何尺度和用户 min 不相容会失败。
高曲率复杂轮廓仍有较多阶梯矩形，全局轴线传播可显著增加物性单元数；
与允许外扩的旧模型比较 region 数时，必须同时比较外扩面积和完整单元语义。
测量证据与采样误差见 architecture-validation.json 和修复记录 09。
